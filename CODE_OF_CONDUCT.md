# Code of Conduct

This project aims to provide a respectful, welcoming space for people with different backgrounds and levels of experience. Participation in Issues, Pull Requests, discussions, and other project spaces is covered by this code.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on ideas and code, not people.
- Welcome questions and explain disagreements in good faith.
- Respect privacy. Do not post another person's personal information or private project data.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate intimidation, unwanted sexual attention, and publishing private information without consent are not acceptable.

## Enforcement

The maintainer may edit or remove contributions and may restrict participation when behavior violates this code. To report a concern privately, use a contact method listed on the repository owner's GitHub profile. If none is available, open a minimal issue asking for a private contact route without describing the incident publicly.

This policy is adapted from the principles of Contributor Covenant 2.1.
