# Security Policy

## Supported versions

There are no tagged releases yet. During initial development, report security issues against the current `main` branch. Once releases begin, security fixes will target the latest stable release.

## Reporting a vulnerability

Please do not disclose vulnerabilities in public Issues or Pull Requests.

Use the repository's private vulnerability reporting option from the Security tab. Include the affected version or commit, impact, and concise reproduction details. Redact credentials, real client information, proposal contents, and private freelancer data.

If GitHub does not offer the private reporting option, open a minimal issue asking the maintainer for a private contact route. Do not include vulnerability details in that issue.
